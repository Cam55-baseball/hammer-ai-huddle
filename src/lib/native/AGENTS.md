- iPhone-only features resolve via `src/lib/native/nativeFlags.ts` (off on web) and start from `NativeBridge`; pushes go only `push_enqueue` → `push_outbox` → `send-push`, recipients/words from `_shared/push/fanout.ts`. Why: web unchanged; push only reaches who sees the in-app notice.
- Apple Health writes go only through `healthCards.ts` → `healthWorkouts.ts` (custom `HealthWorkoutPlugin.swift`, id per completion in `health_workout_writes`); real times come only from `workTimeJournal.ts`, fed by the log/drill save paths; reading stays on `@capgo/capacitor-health`; UI only in `AppleHealthSettings`. Why: one honest-time source, no duplicates, nothing on Today.
- Custom Swift plugins live in `ios/App/` (the Xcode root group), registered in `HammersBridgeViewController`. Why: files only under `ios/App/App/` are not found by the project.
- Notification permission for existing players lives in `pushPermission.ts` (one ask via `ExistingPlayerPushPrompt`, remembered in localStorage + Preferences; Settings control `PhoneNotificationsControl`); both are inert unless iPhone app + native_push_v1. The iPhone "last seen" build goes only through `buildInfo.ts` → `record_app_build_seen`. Why: never nag, web unchanged, one owner-readable build record.
